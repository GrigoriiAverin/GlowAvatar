# GlowAvatar

Небольшой инструмент для подготовки аватарок/логотипов, которые «светятся»
ярче обычного белого на HDR-экранах (iPhone/iPad, MacBook, HDR-мониторы
Windows) — тот самый трюк, который сейчас используют для LinkedIn.

Проверено вживую: на реальном HDR-ноуте, в Chromium-браузере (Brave), логотип
после экспорта действительно светится ярче окружающего интерфейса.

## Скачать и запустить

**Без установки Python** — скачай готовую сборку со страницы
[Releases](../../releases/latest):
- **Windows** — `GlowAvatar-windows.exe`. SmartScreen на неподписанном exe
  покажет предупреждение «Windows защитила ваш компьютер» — это нормально,
  жми **«Подробнее» → «Выполнить в любом случае»**.
- **macOS** — `GlowAvatar-macos.zip`, внутри `GlowAvatar.app`. Gatekeeper на
  неподписанное приложение при первом запуске тоже будет ругаться — открой
  через **правый клик по иконке → «Открыть» → «Открыть»** (обычный двойной
  клик на первый раз не сработает).

Обе сборки собираются автоматически на каждый релиз через GitHub Actions
(`.github/workflows/build-release.yml`) — Windows- и macOS-раннерами, без
моей локальной Windows-машины для Mac-версии.

**Из исходников (Windows/macOS/Linux, нужен Python 3.10+):**
```
pip install -r requirements.txt
python glow_avatar_gui.py
```
На Windows можно просто дважды кликнуть `run.bat`.

## Как это работает

LinkedIn (и большинство соцсетей) при загрузке вырезает HDR-метаданные
(gain map, MPF/XMP), но сохраняет встроенный ICC цветовой профиль. Поэтому
HDR прячут внутрь цветового профиля: пиксели кодируются через профиль
«Rec2020 Gamut with PQ Transfer» (гамма Rec.2020 + функция квантования PQ /
SMPTE ST 2084, плюс ICC v4 теги `cicp`+`lumi`, без которых Chromium не даёт
изображению реальный HDR-headroom). Цветоуправляемые браузеры на HDR-экране
интерпретируют такие пиксели не как «100% белого», а как абсолютную яркость
в нитах — отсюда и свечение. На обычном SDR-экране то же фото выглядит как
обычное качественное фото без искажений.

Программа сама, локально, строит нужный ICC-профиль (см. `icc_profile.py`)
и делает всю цветовую математику (`colorimetry.py`, `glow_core.py`) —
никаких сторонних `.icc`-файлов или интернета в рантайме не нужно.

## Использование

1. **«Открыть фото…»** — выбери квадратное или любое фото (центр
   автоматически обрежется в квадрат).
2. Нарисуй маску свечения:
   - **Кисть** — мягкая (регулируется «мягкостью края») кисть; повторные
     мазки не «пересвечивают» друг друга.
   - **Ластик** — уменьшает маску.
   - **Градиент (линейный/радиальный)** — тянешь мышью, получаешь плавный
     переход (например, кольцо свечения по контуру аватарки).
   - **Волшебная палочка (по цвету)** — кликаешь по цвету (например,
     оранжевому на лого), выделяется связная область похожего цвета
     («Допуск цвета» — насколько похожий; связная — значит только то, что
     соединено с точкой клика, а не все похожие пиксели по всей картинке).
   - **«Построить маску по яркости»** — авто-подсказка по ярким/белым
     пикселям.
   - Маска не бинарная — значения плавные 0..1, то есть градиенты
     поддерживаются нативно.
3. **«Целевая яркость свечения»** — слайдер в «стопах» экспозиции (+2 стопа
   ≈ 800 нит по умолчанию, максимум ≈ 4000 нит). Насыщенный цвет физически
   не может светиться так же ярко, как белый (у HDR-панелей ниже пиковая
   яркость для чистого цвета) — для более сильного и честного эффекта есть
   **«Отбеливание при максимуме»** (0 = выключено, только подъём яркости).
4. **Размер выходного файла** — любое число px (квадрат).
5. **«Экспортировать…»** — сохраняет Progressive JPEG со встроенным
   Rec2020-PQ ICC-профилем. Готово к загрузке на LinkedIn.

## Важно

- **На обычном мониторе свечения видно не будет** — предпросмотр в программе
  показывает лишь слегка засвеченные зоны маски (для удобства редактирования),
  а не реальный HDR-эффект. Проверяй на устройстве с HDR-экраном и включённым
  HDR. **Скриншот тоже не покажет свечение** — большинство инструментов
  захвата экрана снимают уже сведённую в SDR картинку, смотри глазами на сам
  экран.
- Эффект зависит от экрана и браузера зрителя; на SDR-экранах и в браузерах
  без цветоуправления фото выглядит как обычное качественное фото.
- Никогда не пересохраняй экспортированный файл в другом редакторе/конвертере
  — это обычно убивает встроенный ICC-профиль вместе с эффектом.
- Соцсети могут в любой момент начать вырезать/перекодировать и ICC-профили —
  не гарантированно вечный трюк.
